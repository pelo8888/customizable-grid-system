Containers And Margins

Start with a plain container when the row should occupy the full line. Add `.margin` when the row itself needs breathing room against the viewport.

Responsive Helpers

The helpers override width below the configured breakpoint so you can keep desktop fractions in place while forcing a simpler mobile layout.

`mq-small`

Turns items into three-per-row units below 650px.

`mq-small` Three items per row below the breakpoint.
`mq-medium` Two items per row below the breakpoint.
`mq-big` One full-width item per row below the breakpoint.

Quick Reference

A compact cheat sheet is more useful than forcing people to inspect the generated CSS when they just need to remember the naming pattern.

Class Pattern

.colX-of-Y means an item spans X columns out of Y.

Examples

  • .col1-of-2 for a half-width column
  • .col3-of-12 for a quarter-width column
  • .col8-of-12 for a main content area

Modifiers

  • .margin adds outer container inset
  • .no-margin removes item margins
  • .mq-* changes mobile layout below the breakpoint

6

Customize The System

The Sass variables are the real API. Change them, rebuild the generated CSS, and reload this page to validate the result visually.

Key Variables

  • $cant-col controls the maximum number of generated columns
  • $max-width controls when the responsive helpers activate
  • $margin-left and related variables control gutters
  • $string-name and $string-separator control class naming

Workflow

npm run build
open example/index.html

Source Files

  • sass/_gridVars.scss for variables
  • sass/grid.scss for grid output
  • sass/inputs.scss for input output
  • css/*.css for generated distributables
